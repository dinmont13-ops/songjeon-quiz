# 송전전기원 예상문제

Next.js(App Router) 기반 4지선다 객관식 문제풀이 웹앱입니다. Vercel에 바로 배포할 수 있는 구조입니다.

## 화면 구성

- 메인 화면: 타이틀 아래 A~F 유형 버튼(3열 2행)
  - A~E 버튼: 클릭하면 "문제 순서 랜덤" / "보기 순서 랜덤" 체크박스와 "문제풀기" 버튼이 나타남
  - F 버튼: A~E 문제를 모두 합쳐 20문제를 무작위로 뽑고, 문제 순서와 보기 순서를 항상 랜덤 적용
- 문제풀이 화면: 한 문제씩 이동(이전/다음), 즉시 채점 없이 전체 문제를 다 푼 뒤 결과 화면에서 한번에 채점
- 결과 화면: 총점, 정답률, 문제별 정답/오답 및 오답인 경우 내 답/정답 비교

## 폴더 구조

- `data/questions.js` — A~E 유형별 문제 데이터 (현재는 샘플 5문제, 유형당 20문제로 교체 예정)
- `lib/shuffle.js` — 배열 셔플 유틸
- `components/Quiz.js` — 문제풀이 로직 (순서/보기 랜덤화, 전체 제출 후 채점)
- `app/page.js` — 메인 화면 (유형 선택 + 랜덤 옵션)
- `app/quiz/[type]/page.js` — 유형별 문제풀이 페이지 (F형은 A~E 병합)
- `app/layout.js`, `app/globals.css` — 레이아웃/스타일

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속

## Vercel 배포 방법

### 방법 A: GitHub 연동 (추천)
1. 이 폴더를 GitHub 저장소로 push
2. https://vercel.com 에서 "Add New Project" → 해당 저장소 선택
3. Framework는 Next.js로 자동 인식됨 → Deploy 클릭

### 방법 B: Vercel CLI로 바로 배포
```bash
npm i -g vercel
vercel
```
안내에 따라 로그인 후 진행하면 배포 URL이 생성됩니다.

## 문제 데이터 교체 방법

`data/questions.js` 파일을 열어 A~E 유형별 배열에 아래 형식으로 문제를 추가/수정하세요. (유형당 20문제 예정)

```js
{
  id: 6,
  question: "문제 내용",
  options: ["보기1", "보기2", "보기3", "보기4"],
  answerIndex: 0, // 정답 보기의 인덱스 (0=보기1, 1=보기2, ...)
  explanation: "해설 (선택사항)",
}
```

F형은 별도 데이터 없이 A~E 데이터를 코드에서 자동으로 합쳐서 사용하므로, A~E만 채우면 F형도 함께 완성됩니다.

문제 파일(엑셀/워드/텍스트 등)을 주시면 이 형식으로 변환해서 자동으로 채워드릴 수 있습니다.
